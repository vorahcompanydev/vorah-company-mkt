# Banco de ideias

Ideias soltas de conteúdo, campanha, template ou serviço. Ideia não é item aprovado: não vai para `conteudos-aprovados/` até a usuária aprovar.

## Como registrar

- Todas as ideias ficam em `ideias.md`, uma por bloco, da mais recente para a mais antiga.
- Cada ideia tem: título, descrição (as palavras da usuária, sem reescrever), marca (padrão `vorah-company`), data, status e observações.
- Status: `nova`, `em desenvolvimento`, `aprovada` (já copiada para `conteudos-aprovados/`) ou `descartada`.
- Commit com prefixo `ideia:` e push imediato na branch atual.
