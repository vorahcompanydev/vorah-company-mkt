# Banco de imagens

Fotos enviadas pela usuária para usar nos layouts de conteúdo. Não é conteúdo aprovado: a imagem só vira parte de um conteúdo quando ele for aprovado e salvo em `conteudos-aprovados/`.

## Como registrar

- Nome do arquivo: `AAAA-MM-DD_descricao-curta.jpg` (data em que a usuária enviou).
- Cada imagem entra na tabela abaixo com uma descrição do que aparece (sem identificar pessoas) e a observação de direitos.
- Commit com prefixo `docs:` e push imediato na branch atual.

## Direitos de uso

Várias imagens parecem cenas de filmes, séries ou memes, ou fotos de terceiros. Antes de publicar, principalmente em conteúdo impulsionado, confirmar o direito de uso ou trocar por foto própria ou de banco livre (Unsplash, Pexels).
