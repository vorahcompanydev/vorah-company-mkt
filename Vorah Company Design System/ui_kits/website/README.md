# UI Kit — Vorah Company marketing site

A high-fidelity, interactive recreation of the Vorah Company website
(https://www.vorahcompany.com/), rebuilt from the live site's copy and
structure using this design system's tokens and components.

## Run
Open `index.html`. It loads `../../styles.css` and `../../_ds_bundle.js`
(auto-generated by the compiler), then mounts the React sections.

## Sections (files)
- `Nav.jsx` — sticky header: logo, links, WhatsApp CTA, mobile menu toggle.
- `Hero.jsx` — "Aumentar vendas nas redes sociais?" + CTA + pricing band.
- `Differentials.jsx` — the four diferenciais (💬 🤝 🧭 🎯).
- `WhatWeDo.jsx` — numbered 01–05 outcomes + "o que oferecemos" service list.
- `Results.jsx` — "impacto em números" stats on a dark band.
- `About.jsx` — "Conectamos marcas e pessoas com intenção."
- `Testimonials.jsx` — client quotes.
- `Contact.jsx` — "Entre em contato conosco" form (interactive, fake submit).
- `Footer.jsx` — contact details, social, legal.
- `App.jsx` — composes the page; handles mobile-menu + form state.

## Interactivity
- Mobile menu opens/closes.
- Anchor links scroll to sections.
- Contact form validates required fields and shows a success state (no network).

## Notes
- **Imagery:** the live site uses licensed Wix stock photography not present in
  this project. Photo areas are rendered as on-brand placeholder panels (earth
  tones + flower mark). Drop real images in to finalize.
- Components come from `window.VorahCompanyDesignSystem_0977e7`; section
  components are namespaced on `window.VK`.
