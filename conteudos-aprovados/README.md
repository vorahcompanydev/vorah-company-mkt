# Conteúdos aprovados

Aqui ficam todos os conteúdos que a usuária aprovou (copy, legendas, roteiros de carrossel e Reels, calendário editorial, templates, etc.).

## Como salvar

- Um arquivo por item aprovado, em Markdown (`.md`). Artes e imagens podem ficar ao lado, com o mesmo nome base.
- Nome do arquivo: `AAAA-MM-DD_marca_tipo_titulo-curto.md` (minúsculas, sem acento, hífens).
  * Exemplo: `2026-10-16_vorah-company_carrossel_o-seu-negocio-ja-e-bom.md`
- Para a Vorah, usar `vorah-company` como marca. Para clientes, o slug da marca (ex.: `occatu`).
- No topo de cada arquivo, registrar: marca, tipo, data da aprovação e status.
- Commit com mensagem começando por `aprovado:` e push imediato na branch atual.
