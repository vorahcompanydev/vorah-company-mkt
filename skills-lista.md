# Skills do repositório (`.claude/skills/`)

## 1. Marca e design

| Skill | O que faz |
|---|---|

| `canvas-design` | Cria peças visuais estáticas (pôster, arte) em PNG e PDF. |
| `algorithmic-art` | Arte generativa com p5.js: flow fields, partículas, parâmetros interativos. |
| `web-artifacts-builder` | Monta artifacts HTML complexos com React, Tailwind e shadcn/ui. |
| `mermaid-diagrams` | Diagramas com Mermaid: fluxogramas, sequência, ER, C4, gantt, estados. |
| `meme-factory` | Gera memes pela API memegen.link (mais de 100 templates). |

## 7. Não ativa: `ai-sales-team`

É uma coleção com instalador próprio (`install.sh`) e não tem `SKILL.md` na raiz. Por isso o Claude Code não a enxerga. Os 14 comandos são roteados pelo `ai-sales-team/sales/SKILL.md`, e cada um tem seu arquivo em `ai-sales-team/skills/`:

| Comando | O que faz |
|---|---|
| `/sales prospect <url>` | Análise completa de prospect, com 5 agentes em paralelo e nota de 0 a 100. |
| `/sales research <url>` | Pesquisa de empresa e dados firmográficos. |
| `/sales contacts <url>` | Mapeia o comitê de compra e os tomadores de decisão. |
| `/sales qualify <url>` | Qualificação de lead com BANT e MEDDIC. |
| `/sales competitors <url>` | Ferramentas que o prospect usa e battle cards. |
| `/sales outreach <prospect>` | Sequência de cold e-mail com toques no LinkedIn. |
| `/sales followup <prospect>` | Sequência de follow-up depois de reunião, demo ou proposta. |
| `/sales prep <url>` | Briefing de preparação para reunião. |
| `/sales proposal <cliente>` | Proposta comercial. |
| `/sales objections <tema>` | Playbook de respostas a objeções. |
| `/sales icp <descrição>` | Perfil de cliente ideal. |
| `/sales report` | Relatório de pipeline em markdown. |
| `/sales report-pdf` | Relatório de pipeline em PDF (precisa de Python e `reportlab`). |
| `/sales quick <url>` | Resumo rápido do prospect (cerca de 60 segundos), direto no terminal. |
